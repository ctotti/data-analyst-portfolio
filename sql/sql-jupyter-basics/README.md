# SQL Jupyter Basics

A collection of study notebooks exploring SQL workflows and database interaction using **Jupyter Notebook**.

## Contents

### PostgreSQL with Jupyter

The first notebook explores two approaches for connecting to and querying a PostgreSQL database from Jupyter:

* **ipython-sql** — execute SQL queries directly in Jupyter using SQL magic commands.
* **SQLAlchemy** — connect to PostgreSQL through Python and retrieve query results into Pandas.

The examples use an NYC taxi dataset and a PostgreSQL database with PostGIS enabled.
