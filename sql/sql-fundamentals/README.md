- **Study Database:** AdventureWorks2017

## 🗺️ Study Roadmap

The notes and scripts cover the following topics in this order:

1.  **Environment Setup:** Installing SQL Server and SSMS, restoring the AdventureWorks database.
2.  **Basic Queries:** `SELECT`, `DISTINCT`, `WHERE`, `COUNT`, `TOP`, `ORDER BY`.
3.  **Filters and Operators:** `BETWEEN`, `IN`, `LIKE`.
4.  **Aggregate Functions and Grouping:** `MIN`, `MAX`, `SUM`, `AVG`, `GROUP BY`, `HAVING`.
5.  **Joins:** `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, `FULL OUTER JOIN`, `SELF JOIN`, `UNION`.
6.  **Subqueries:** Subselects.
7.  **Advanced Functions:** `DATEPART`, String Manipulation, Mathematical Operations.
8.  **Data Modeling:** Data Types, Primary and Foreign Keys.
9.  **Data Manipulation Language (DML):** `CREATE TABLE`, `INSERT INTO`, `UPDATE`, `DELETE`.
10. **Data Definition Language (DDL):** `ALTER TABLE`, `DROP TABLE`, `TRUNCATE`.
11. **Constraints:** `NOT NULL`, `UNIQUE`, `CHECK`, `PRIMARY KEY`, `FOREIGN KEY`.
12. **Views:** `CREATE VIEW`.

## 🎯 How to Use This Material

1.  **Read the notes (`notes.md`)** to understand the theory and syntax of each command.
2.  **Run the scripts (`scripts/sql-fundamentals.sql`)** in SSMS (or your preferred tool) to see the concepts in action and practice.
3.  **Follow the lesson order** for a gradual and consistent learning experience.
