# Titanic Data Cleaning

## Overview

This project focuses on cleaning and preparing the Titanic dataset for further data analysis.

The main goal was to identify and handle missing values, correct data types, remove inconsistencies, and prepare the dataset for exploratory analysis.

## Objectives

- Inspect the structure and quality of the dataset
- Identify missing and inconsistent values
- Clean and transform relevant variables
- Prepare the dataset for further analysis
- Document the data cleaning process

## Tools

- Python
- Pandas
- Jupyter Notebook

## Dataset

The project uses the Titanic dataset, containing information about passengers aboard the RMS Titanic, including demographic information, passenger class, and survival status.

## Data Cleaning Process

The notebook includes:

- Initial data exploration
- Missing-value analysis
- Data type verification
- Handling of missing values
- Data transformation
- Removal of unnecessary information
- Final validation of the cleaned dataset
